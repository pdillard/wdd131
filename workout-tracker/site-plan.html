Workout Tracker - Site Plan

Purpose

This web application allows users to log workouts, track exercises, and monitor progress over time. It helps users stay consistent and organized with their fitness routine.

Audience

Individuals who go to the gym or exercise regularly and want a simple way to track their workouts. This includes beginners and intermediate users who want a clean, simple tracking tool.

Dynamic Elements

  • Add new workouts (exercise, sets, reps, weight)
  • Edit and delete workouts
  • Store workout data using local storage
  • Filter workouts by exercise or date
  • Display progress over time

Logo

FitTrack - A bold, simple, fitness-focused text logo.

Color Scheme

  • Primary: #111827
  • Secondary: #EF4444
  • Accent: #22C55E
  • Background: #F3F4F6
  • Text: #000000

Fonts

  • Headings: Roboto Condensed
  • Body: Open Sans

Content

Home

Track your workouts. Build consistency. Improve your results.

Workout Log

Users can view a list of workouts including exercise name, sets, reps, weight, and date.

Add Workout Form

Users can input exercise name, sets, reps, weight, and date.

Progress

Users can review past workouts and see improvements over time.

Wireframe

Home Page

  • Header with logo and navigation
  • Main section with title and description
  • Call-to-action button

Workout Page

  • Add workout button at top
  • Form section
  • Workout list below (cards or table)
