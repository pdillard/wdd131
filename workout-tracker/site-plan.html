Site Plan

WDD 131 Final Project · Preston Dillard

Purpose

This web application allows users to log workouts, track exercises, and monitor progress over time. It helps users stay consistent and organized with their fitness routine.

Audience

Individuals who go to the gym or exercise regularly and want a simple way to track their workouts. This includes beginners and intermediate users who want a clean, simple tracking tool.

Dynamic Elements

  • Add new workouts (exercise, sets, reps, weight)
  • Edit and delete workouts
  • Store workout data using local storage
  • Filter workouts by exercise or date
  • Display progress over time

Content

Home

Track your workouts. Build consistency. Improve your results.

Workout Log

View a list of workouts including exercise name, sets, reps, weight, and date.

Add Workout

Input exercise name, sets, reps, weight, and date via a form.

Progress

Review past workouts and see improvements over time.
